## 归档约定

- 每批使用 `年份/YYYY-MM-DD-主题/`，例如 `2026/2026-11-20-us-equities/`。目录日期采用报告的数据截止日。
- 批次的 `README.md` 放摘要和报告链接，个股报告用股票代码命名。共享估值参数和报告引用的复算底稿随批次归档。
